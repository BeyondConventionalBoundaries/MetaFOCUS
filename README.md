# MetaFOCUS

MetaFOCUS is a free Python toolbox for Agisoft Metashape Professional that makes detailed diagnostic information about Structure-from-Motion projects accessible through graphical tools within Metashape.

Version 1.0.0 will be released here when the paper that describes the toolbox is published:

Verhoeven, G., Ressl, C., Wieser, M. (2026). MetaFOCUS: a Python Toolbox for Optimising, Characterising and Understanding Structure-from-Motion Pipelines in Agisoft Metashape Professional.

MetaFOCUS will be released under the GNU General Public License, version 3 or later, with an additional permission to convey MetaFOCUS combined with Agisoft Metashape and its Python module.
